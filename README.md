# 数独大师 100

**在线玩：<https://yjj0339.github.io/sudoku-master-100/>**

从入门到地狱的 100 关数独闯关游戏，手机竖屏 + 电脑宽屏双端，浅色玻璃拟态界面，零依赖纯前端。

- 支持 **PWA 离线游玩**：第一次打开后自动缓存全部资源，之后秒开、断网也能玩，还可以「添加到主屏幕」当 App 用（发新版需把 `sw.js` 里 `CACHE` 版本号 +1）。

## 特色

- **100 关精心分档**：入门(1-10) → 新手(11-25) → 进阶(26-45) → 高手(46-65) → 大师(66-85) → 宗师(86-99) → 👑地狱终局(100)。关卡离线预生成，全部校验唯一解，难度用「人类解题技巧评分」控制曲线（唯一余数 → 隐性唯一 → 区块摒除 → 数对/三链数 → X-Wing/Swordfish → 链染/XY-Wing → 深层推理）。
- **第 100 关地狱终局**：仅 23 个提示、技巧链 134 分，常规技巧用尽后需深层推理，连 AI 也要认真起来。
- **AI 大师「玄机」**：只讲不填 / 指点一步 / 演示到底。逐步讲解每一步用的是哪种技巧、为什么成立。
- **两级提示**：第一次指出该填哪格并讲原理，再点一次才填入；盘面有矛盾时先帮你标红错误。
- **完整工具**：笔记（自动清理同行列宫候选）、撤销、擦除、即时纠错、同数高亮、剩余计数、计时暂停、切后台自动暂停。
- **进度系统**：三星评级、顺序解锁、10 个成就、自动存档（玩一半关掉浏览器也能续）。
- 音效 + 震动反馈（均可关），支持键盘操作（数字键/退格/Z撤销/H提示/N笔记）。

## 目录

- `index.html` + `css/` + `js/` 站点本体，零依赖
- `js/engine.js` 数独引擎：生成器、唯一解计数、13 种人类技巧求解器与评分
- `js/levels-data.js` 预生成 100 关数据（由 `tools/gen-levels.js` 离线产出）
- `tools/` 生成器与 Playwright 冒烟测试（`python tools/smoke.py`，需本地 8917 端口）
